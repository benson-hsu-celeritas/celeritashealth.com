## Worth doing
A made-up reference is the failure that shuts a pilot down. I wanted the rate in a deployed library, measured by a method that runs on public bibliographic data.

## Build or buy
The fix is omit-then-verify. The model is told not to write identifiers at all. The code looks each reference up through NCBI E-utilities and accepts a match only when the title tokens line up; anything else is marked unverified. The code and the verification script are in the open deposit.

## Rules
An unverifiable reference is not a fabricated one. The operator needs three categories: verified, topic mismatch, not found. Most not-found items were real sources outside PubMed: a WHO guideline, a drug monograph, a 1944 article.

## Is it working
Yes. 279 of 298 verified, with a confidence interval, reproducible from public bibliographic data; the script is in the deposit. The paper is under review, so the numbers could move.
