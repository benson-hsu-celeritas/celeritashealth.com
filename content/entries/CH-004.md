## Worth doing
This work says not to trust a number that cannot be regenerated. In June 2026 I applied that rule to my own manuscripts.

## Build or buy
I made a manifest, one row per number in every manuscript, with the file that produces it. If there was no file, the row was marked as coming from the summary and treated as unverified.

## Rules
A number goes on this site only if a deposited file regenerates it. The seven that failed stay off, including rounded or reworded versions.

## Is it working
Yes. The papers that remain rest on logged facts and public deposits. The cost was two manuscripts and a month.
